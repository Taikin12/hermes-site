PRIVACY POLICY

プライバシーポリシー

制定日: 2026年11月18日 / 最終改定日: 2026年11月18日

本プライバシーポリシーは、個人が運用する AI エージェント「Hermes」（以下「本サービス」）における、 Google アカウントを通じて取得する情報の取り扱いを定めるものです。 本サービスは、利用者（Google アカウントの所有者本人）が明示的に同意した場合にのみ、 Google カレンダーへアクセスします。

1. 取得する情報

本サービスは、Google の OAuth 2.0 同意画面で利用者が許可した範囲に限り、次の情報を取得します。

情報 内容 取得の根拠
Google アカウントの基本プロフィール 氏名、メールアドレス、プロフィール画像、Google アカウントの識別子 接続先アカウントの特定および本人確認のため
Google カレンダーのデータ カレンダー一覧、予定のタイトル、日時、場所、説明、参加者、繰り返し設定などの予定情報 予定の読み取り・作成・更新のため
認証情報 OAuth アクセストークンおよびリフレッシュトークン 許可された範囲で Google API を呼び出すため

本サービスは、Google カレンダーへのアクセス権限（https://www.googleapis.com/auth/calendar）を 利用者の同意を得て要求します。この権限には予定の参照・作成・変更・削除が含まれます。

2. 利用目的

  • 利用者の依頼に基づく予定の読み取り、一覧表示、空き時間の確認
  • 利用者の依頼に基づく予定の作成、変更、削除
  • 日程調整や予定の重複解消の提案
  • 上記に付随する、利用者本人への応答の生成

取得した情報を、上記以外の目的で利用することはありません。

3. 保存と管理

  • OAuth トークンは、利用者本人の端末上のローカル環境にのみ保存します。
  • 予定データは、応答の生成に必要な範囲で一時的に処理し、恒久的なデータベースへの蓄積は行いません。
  • ローカルに保存される認証情報は、利用者本人が管理する環境のファイル権限に従って保護されます。

4. 第三者提供・共有

  • 取得した情報を第三者へ販売、貸与、提供することはありません。
  • 広告配信、プロファイリング、信用評価などの目的で利用することはありません。
  • AI モデルによる応答生成のためにデータを送信する場合、その内容は処理目的の範囲に限定され、学習目的での再利用は行いません。
  • 法令に基づく開示請求があった場合を除き、外部へ開示しません。

5. Google API サービス ユーザーデータ ポリシーへの準拠

Hermes's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

（日本語参考）本サービスによる Google API から取得した情報の利用および他のアプリへの移転は、 Limited Use 要件を含む Google API サービス ユーザーデータ ポリシーに準拠します。

6. 保存期間と削除

取得した情報は、利用目的の達成に必要な期間だけ保持します。 利用者は次の方法で、いつでもデータの削除とアクセス権の取り消しを行えます。

  1. Google アカウントの「セキュリティ」→「サードパーティのアプリとサービス」から 本サービスへのアクセス権を取り消す。
  2. 利用者本人の端末から、保存された OAuth トークンのファイルを削除する。
  3. taikinkbd@gmail.com へ削除を依頼する。 依頼を受領後、合理的な期間内（遅くとも30日以内）に削除します。

アクセス権を取り消すと、本サービスは Google カレンダーへアクセスできなくなります。

7. セキュリティ

  • Google API との通信は TLS により暗号化されます。
  • OAuth の認証情報は、必要最小限の範囲と権限でのみ保持します。
  • 不要になった認証情報は速やかに削除します。

8. 子どもの利用

本サービスは、13歳未満の方を対象としていません。

9. ポリシーの変更

本ポリシーを変更する場合は、本ページに改定日とともに掲載します。 重要な変更がある場合は、本サイト上で分かりやすく告知します。
